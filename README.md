## 📐 How to Adjust the K-Factor for Standard DIY Materials

The **K-Factor** represents how the metal stretches when it is bent. For most home studio projects, getting this value right ensures your custom brackets and mounts line up perfectly without wasting materials.

To map out your flat pattern accurately, use these guideline values for the K-Factor:

### K-Factor Settings
* **Standard 5052-H32 Aluminum:** Set the K-Factor to **`0.45`**. This alloy is the gold standard for DIY creators because it is lightweight, strong, and easy to form with simple hand tools or a standard workshop vise.
* **Standard Steel / Mild Steel:** Set the K-Factor to **`0.45`**.
* **Stainless Steel:** Set the K-Factor to **`0.35`** to account for how the harder material stretches differently during a bend.
* **Soft Materials (Copper / Brass):** Set the K-Factor to **`0.50`** to compensate for the higher rate of material flow during forming.
